# مواصفات التقويم الأسري v1

## الغرض
إضافة أحداث أسرية ومواعيد مرتبطة بطفل، مع فرز حسب الفترة، وتعديل وحذف الحدث.

## حقول الحدث في النموذج المحلي
- `id`: معرف محلي.
- `title`: اسم الحدث (مطلوب، حتى 120 حرفًا).
- `date`: تاريخ محلي `YYYY-MM-DD` (مطلوب).
- `time`: وقت اختياري `HH:MM`.
- `type`: موعد عائلي، موعد طبي، تطعيم، حضانة/مدرسة، نشاط، عيد ميلاد، أخرى.
- `childId`: معرف طفل أو `null` للأسرة كلها.
- `repeat`: `none`, `weekly`, `monthly`, `yearly`.
- `note`: ملاحظات اختيارية حتى 500 حرف.
- `createdAt`: وقت إنشاء ISO عند إضافة الحدث.

## الوظائف المنفذة
- إضافة حدث وتعديله وحذفه.
- عرض كل الأحداث أو فلترتها بتاريخ بداية ونهاية.
- اختصارات لليوم والأيام السبعة القادمة.
- ترتيب حسب التاريخ ثم الوقت.
- ربط الحدث بطفل أو بالأسرة كلها.
- تطبيع بيانات التخزين القديمة التي لا تتضمن `events`.

## حدود معروفة
- التكرار يُعرض ويُحفظ فقط ولا يُنشئ نسخًا متكررة.
- الملاحظات ليست إشعارات فعلية.
- لا توجد مزامنة أو حسابات أو صلاحيات خادم.
- الأحداث محفوظة في `localStorage`، ويمكن فقدها عند مسح بيانات المتصفح.
- نموذج أولي وليس سجلًا طبيًا معتمدًا أو تقويمًا إنتاجيًا.

## معايير قبول يدوية
1. إضافة حدث بتاريخ ووقت واختبار ظهوره مرتبًا.
2. إضافة حدث مرتبط بطفل واختبار الاسم الظاهر.
3. فلترة نطاق التاريخ والتحقق من النتائج.
4. تعديل عنوان حدث وحفظه.
5. حذف حدث بعد تأكيد المستخدم.
6. فتح نسخة بيانات قديمة دون `events` والتحقق من عدم حدوث خطأ.
7. اختبار إدخال HTML كنص عنوان والتأكد من عرضه كنص لا كعنصر تنفيذي.
